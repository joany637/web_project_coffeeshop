# Triple Espresso
Este proyecto es una landing page para una cafetería desarrollada como práctica de desarrollo web. El sitio muestra información sobre la cafetería, el menú, reservas y la experiencia del lugar a través de una interfaz moderna y responsive.

El objetivo del proyecto fue practicar la estructura de páginas web, estilos y organización del código utilizando tecnologías básicas del desarrollo frontend.
Tecnologías utilizadas

HTML5

CSS3

JavaScript

Metodología BEM

Flexbox

Grid Layout
